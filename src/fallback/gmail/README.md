# Gmail Fallback Parser

This folder is intentionally disabled by default.

Etsy Open API v3 currently does not expose an official endpoint for buyer conversations, messages, or message attachments for this use case. If you enable Gmail notification emails from Etsy, a future fallback parser can read those emails through an official Gmail API integration and forward safe summaries to Telegram.

Do not use this folder to scrape Etsy pages or call private/internal Etsy APIs.
